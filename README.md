# Programming Logic Exercises

Standalone programming logic exercises written in Java. They build the problem solving foundation I need for [Harvard CS50](https://cs50.harvard.edu/) and are the starting point of a longer plan to study the same fundamentals across Java, C, C# and Python.

## About

Each file in [`src/ProgrammingLogic/`](src/ProgrammingLogic/) is a self contained exercise with its own `main()` method, written from scratch while following the [DevDojo Programming Logic course](https://docs.google.com/document/d/1yt9gyXl8GbRqqIt_WeZe4zjzKdaH_44i5_3LS8s2zSU/edit?pli=1&tab=t.0). No frameworks and no build tools, just plain Java and the standard library, so the focus stays on the logic.

This is an ongoing study. New exercises are added as I keep working through the material.

## Topics

The exercises currently cover:

* Variables and basic input/output
* Arithmetic and calculators (if, switch and enum based)
* Conditionals and decision logic
* Loops and sequences (sums, multiplication tables, Fibonacci, prime numbers)
* Math and geometry (areas, volumes, number theory)
* Unit conversions (temperature and currency)
* Money and finance (bank notes, change, fuel cost)
* Arrays, search and ordering (min/max, sorting)
* Validation (Brazilian CPF checksum, login with retries)
* Small games (guess the number, rock paper scissors with a simple OOP design)

Browse [`src/ProgrammingLogic/`](src/ProgrammingLogic/) for the full set.

## How to run

Plain IntelliJ IDEA project (Java 21), no build tool.

From IntelliJ, open any `.java` file and run its `main()` method. From the command line:

```bash
javac -d out src/ProgrammingLogic/<ClassName>.java
java -cp out ProgrammingLogic.<ClassName>
```

Most programs read input from the console with `Scanner` and print the result to standard output.
