## 📖 About

This repository is my personal training ground for **programming logic**. Each file in
[`src/ProgrammingLogic/`](src/ProgrammingLogic/) is a self-contained exercise with its own `main()` method —
written from scratch as I work through the
[DevDojo Programming Logic course](https://docs.google.com/document/d/1yt9gyXl8GbRqqIt_WeZe4zjzKdaH_44i5_3LS8s2zSU/edit?pli=1&tab=t.0)
and prepare for **Harvard CS50**.

No frameworks, no build tools — just plain Java and the standard library, so the focus stays on the logic itself.

Java is only the starting point. The plan is to study **programming logic across several languages — Java, C, C# and Python** — using each one to reinforce the same fundamentals from a different angle. This repo grows as that journey continues.

## ▶️ Running an exercise

This is a plain **IntelliJ IDEA** project (Java 21) with no build tool.

**From IntelliJ:** open any `.java` file and run its `main()` method.

**From the command line:**
```bash
# Compile
javac -d out src/ProgrammingLogic/<ClassName>.java

# Run
java -cp out ProgrammingLogic.<ClassName>
```

Most programs read input from the console via `Scanner` and print the result to standard output.
